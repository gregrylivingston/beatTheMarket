# beatTheMarket

A browser game that teaches investing by making you do it badly first.

Built for **[Next Gen Personal Finance](https://www.ngpf.org/)**, the personal finance curriculum nonprofit, as part of their Investing Arena. Students pick holdings, ride the market through a compressed run of history, and find out what their instincts cost them. The lesson lands harder from a portfolio that lost money than from a chart in a slide deck.

This was my first JavaScript web game. I was NGPF's product manager for online professional development at the time, building the virtual PD practice that trained more than a thousand teachers in its first year, and this came out of the same question: what would make this stick.

## Running it

No build step and no dependencies. Download, unzip, open `index.html`.

## Notes

Plain HTML, CSS and JavaScript, written to run on whatever machine a school actually had. That constraint shows up in a lot of my education work: the classroom version has to survive a laptop cart and an unreliable connection.

Dedicated to the great people at NGPF.
